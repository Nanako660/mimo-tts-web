# 语音合成（MiMo-V2.5-TTS 系列）使用指南与提示词工程

> 本文档详细介绍 Xiaomi MiMo-V2.5-TTS 系列语音合成模型的核心特性、支持模型、发音风格控制（自然语言与音频标签）、导演模式、预置音色列表、音色设计 Prompt 技巧以及音色克隆最佳实践。

---

## 1. 核心能力概述

语音合成（Text-to-Speech）支持将输入的文本自动转换为自然流畅的语音输出。通过配置发音风格、音色等参数，生成自然生动的语音内容：

- **预置音色开箱即用**：内置多种精品音色（如冰糖、茉莉、苏打、白桦、Mia 等），无需额外配置即可快速调用。
- **音色设计（Voice Design）**：支持仅通过文本描述设计专属音色，无需提供任何音频样本。
- **音色复刻（Voice Clone）**：基于短音频样本精准复刻任意目标音色。
- **多样化发音风格与情感演绎**：支持语速、情绪、角色扮演、方言等多种风格控制，细腻到字词粒度的呼吸与气音。
- **低延迟流式输出**：`mimo-v2.5-tts` 支持实时流式输出（PCM16 / 24kHz Mono）。

## 2. 支持的模型列表与特性对比

| 模型 ID (Model ID) | 功能定位 | 音色支持 | 核心特性与注意事项 |
| :--- | :--- | :--- | :--- |
| `mimo-v2.5-tts` | 预置精品音色合成 | 使用预置音色列表中的精品音色（默认 `mimo_default`） | • 支持低延迟流式输出<br>• 支持唱歌模式<br>• 不支持音色设计与音色复刻 |
| `mimo-v2.5-tts-voicedesign` | 文本描述定制音色 | 通过文本 Prompt 自动生成音色，无需预置或音频样本 | • 支持智能文本润色 (`optimize_text_preview`)<br>• 不支持唱歌模式、预置音色与音色复刻 |
| `mimo-v2.5-tts-voiceclone` | 音频样本音色复刻 | 通过音频样本精准复刻音色，实现任意声音合成 | • 支持 Base64 编码音频输入（≤ 10MB，mp3/wav）<br>• 不支持唱歌模式、预置音色与音色设计 |

## 4. 风格控制与提示词工程 (Style Control)

MiMo-TTS 支持两种发音风格控制方法：
1. **自然语言控制** → 放在 `role: user` 的 `content` 中
2. **音频标签控制** → 放在 `role: assistant` 的 `content` 中

---

### 4.1 自然语言控制（放在 `role: user`）

通过自然语言描述，让模型理解并生成对应风格的语音。

#### 单句描述法
直接用一句话描述想要的语气、情感和语速：
- *“用轻快上扬的语调向领导报喜，语速稍快，带着查到成绩后压抑不住的激动与小骄傲，声音明亮有活力。”*
- *“看着刚解决的难题成果忍不住得意忘形地惊呼，声音高亢明亮，语速偏快，语气中带着满满的自信与难以置信。”*
- *“用明亮活泼的青少年嗓音，带着恶作剧得逞后的得意与戏谑，语速偏快且咬字轻巧，在强调赌注时语气微微上扬。”*

#### 导演模式 (Director Mode)
针对角色配音、影视级剧本演绎等高要求场景，从**角色**、**场景**、**指导**三个维度进行立体刻画：

```markdown
角色：百年门阀岑家的现任大当家。自出生便被过继给祖庙的守门老人抚养，被塑造成一尊完美无瑕、绝情断欲的家族图腾。常年深居简出，对人有着极强的阶级疏离感。

场景：在祠堂的阴影里，看着那个不顾一切冲破保安防线来找她、企图带她私奔的男人。她要用最冷硬的阶级壁垒，绞杀对方，也绞杀自己刚刚萌芽、却足以燎原的感情。

指导：
冰冷、慵懒却极具威压的低音御姐。发声通道非常松弛，没有任何剑拔弩张，却有着让人骨里生寒的压迫感。

- 语速与顿挫：极慢，每个字都像是在舌尖滚过才吐出来，带着上位者漫不经心的傲慢。句与句之间留下极长的、令人不安的空白。
- 气声与实声：大部分时间，她的声音没有明显的声调起伏，实音重且硬，像是一条平缓却冰冷的暗河。但一定要在某些尾音处（如“真心”），加入极其轻微的气音收束，透出一丝连她自己都没察觉到的疲惫与渴望。
- 咬字肌理：文白杂糅的用词带着旧时代的痕迹，唇齿音发得极轻但极清晰（如“冲撞”“廉价”），显得既清雅又锋利，刀刀见血。
```

### 4.2 音频标签控制（放在 `role: assistant`）

在待合成文本中直接嵌入 `(风格)` 标签和 `[音频标签]`。支持半角 `()`、全角 `（）` 或 `[]`。

#### 1. 开头整体风格标签 `(风格)`
在文本开头添加 `(风格)`，可同时设置多种风格（如 `(慵懒 沙哑)`）：

| 风格类型 | 推荐标签示例 |
| :--- | :--- |
| **基础情绪** | 开心 / 悲伤 / 愤怒 / 恐惧 / 惊讶 / 兴奋 / 委屈 / 平静 / 冷漠 |
| **复合情绪** | 怅然 / 欣慰 / 无奈 / 愧疚 / 释然 / 嫉妒 / 厌倦 / 忐忑 / 动情 |
| **整体语调** | 温柔 / 高冷 / 活泼 / 严肃 / 慵懒 / 俏皮 / 深沉 / 干练 / 凌厉 |
| **音色定位** | 磁性 / 醇厚 / 清亮 / 空灵 / 稚嫩 / 苍老 / 甜美 / 沙哑 / 醇雅 |
| **人设腔调** | 夹子音 / 御姐音 / 正太音 / 大叔音 / 台湾腔 |
| **方言特色** | 东北话 / 四川话 / 河南话 / 粤语 |
| **角色扮演** | 孙悟空 / 林黛玉 等 |
| **唱歌模式** | `(唱歌)`、`sing`、`singing`（需置于开头，歌词推荐中文） |

**示例**：
- `(怅然)这么多年过去了，再走过那条街，心里一下子空了一块。`
- `(东北话)哎呀妈呀，这天儿也忒冷了吧！你说这风，嗖嗖的，跟刀子似的，割脸啊！`
- `(唱歌)原谅我这一生不羁放纵爱自由，也会怕有一天会跌倒，Oh no。`

#### 2. 句中细粒度音频标签 `[音频标签]` / `(动作)`
可在文本任意位置插入动作、气息或情绪变化：

| 控制类型 | 标签示例 |
| :--- | :--- |
| **语速与节奏** | 吸气 / 深呼吸 / 叹气 / 长叹一口气 / 喘息 / 屏息 / 沉默片刻 |
| **情绪状态** | 紧张 / 害怕 / 激动 / 疲惫 / 委屈 / 撒娇 / 心虚 / 震惊 / 不耐烦 |
| **语音特征** | 颤抖 / 声音颤抖 / 变调 / 破音 / 鼻音 / 气声 / 沙哑 |
| **哭笑表达** | 笑 / 轻笑 / 大笑 / 冷笑 / 抽泣 / 呜咽 / 哽咽 / 嚎啕大哭 |

**示例**：
- `（紧张，深呼吸）呼……冷静，冷静。不就是一个面试吗……（语速加快，碎碎念）自我介绍已经背了五十遍了，应该没问题的。（小声）哎呀，领带歪没歪？`
- `如果我当时……（沉默片刻）哪怕再坚持一秒钟，结果是不是就不一样了？（苦笑）呵，没如果了。`

## 5. 音色设计 (Voice Design) 编写指南

当使用 `mimo-v2.5-tts-voicedesign` 模型时，`user` 消息即为音色 Prompt：

### 核心构建维度
1. **性别与年龄**：如 *"young woman in her mid-20s"*、*"五十多岁的中年男性"*
2. **音色与质感**：如 *"deep and gravelly"*、*"丝滑醇厚、带着磁性"*、*"清脆明亮"*
3. **情绪与语气**：如 *"warm and confident"*、*"温柔但带着一丝疲惫"*
4. **语速与节奏**：如 *"slow and deliberate"*、*"语速极快，像连珠炮"*
5. **可选人设与场景**：*深夜电台 DJ、纪录片旁白、八十年代译制片配音*

### 编写禁忌与要点
- **精炼为主**：1~4 句话清晰刻画特征即可，避免堆砌长文。
- **避免自相矛盾**：如不要同时出现 *"稚嫩童声 + 霸道总裁气场"*。
- **避免后期效果词**：不要写混响 (Reverb)、回声 (Echo)、EQ、压缩等后期音频处理词汇。
- **文本与音色匹配**：`assistant` 的合成文本应与设计的音色风格契合（如给治愈系女声搭配晚安独白，而非体育解说）。

## 6. 音色复刻 (Voice Clone) 最佳实践

- **音频格式**：支持 `mp3` 或 `wav`。
- **文件体积**：Base64 编码后字符串 ≤ 10 MB。
- **数据格式**：必须携带 Data URI 前缀，例如：
  `data:audio/wav;base64,UklGRiQAAABXQVZF...` 或 `data:audio/mpeg;base64,//uQxAA...`
- **采样质量建议**：建议使用 16kHz 或更高采样率、单说话人、清晰无杂音的干声样本（建议 5~15 秒有效语音）。
